# Warehouse v10 — тестовая публикация на GitHub Pages

Проект является точной копией `Warehouse/dist` из ZIP-архива Warehouse_Full_Source_v10.zip. В коде сцены изменений не производилось. Добавлены только `.nojekyll` и этот README.

## Настройка GitHub Pages

1. Создайте репозиторий, например `warehouse-test`, на GitHub.
2. Добавьте в корень репозитория *содержимое* этого ZIP (не сам ZIP).
3. Откройте Settings → Pages → Build and deployment → Source: Deploy from a branch.
4. Укажите ветку `main`, папку `/(root)` и нажмите Save.
5. Ссылка появится в Settings → Pages в формате `https://USERNAME.github.io/warehouse-test/`.

Поскольку все ссылки в HTML/JavaScript относительные, проект открывается из подкаталога GitHub Pages.
Для будущих изменений достаточно обновить файлы в ветке `main` — GitHub Pages заново опубликует сайт на том же адресе.

ВНИМАНИЕ: на бесплатном GitHub Pages публикация из репозитория доступна для публичных репозиториев. Не размещайте здесь конфиденциальную планировку компании, персональные данные и сведения, не предназначенные для открытого доступа. Для приватного хранения кода с публичной тестовой страницей можно подключить отдельный хостинг, например Netlify, к приватному GitHub-репозиторию.

В качестве основного архива исходников используйте исходный `Warehouse_Full_Source_v10.zip` — в нём также присутствует конфигурация прежней публикации `.openai/hosting.json`. Этот GitHub Pages ZIP — именно готовая для размещения копия сайта.
