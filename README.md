# Warehouse — интерактивная 3D-модель склада

Тестовый репозиторий для разработки Warehouse v10 на базе Three.js.

## Публикация

1. Загрузите в корень ветки `main` содержимое архива `Warehouse_v10_GitHub_Pages_ready.zip` (распакованные файлы `index.html`, `*.js`, `style.css` и папку `vendor`).
2. В настройках репозитория выберите **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
3. Тестовая ссылка после публикации: https://vladimalokhatko-jpg.github.io/warehouse-test/

Этот репозиторий — отдельная тестовая копия. Исходную онлайн-публикацию ChatGPT Sites он не изменяет.

**Важно:** репозиторий публичный. Не размещайте здесь конфиденциальные схемы компании или персональные данные.
